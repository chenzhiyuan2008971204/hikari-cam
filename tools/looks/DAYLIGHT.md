# Daylight Collection 日光系列

八款專為白天戶外拍攝設計的原創色彩風格。目標是日系相機那種**乾淨、通透、有層次**的日光顏色，
而不是單純疊一層復古黃綠。沒有使用任何廠商的 LUT、程式碼或商標素材；名稱也都是 Hikari 自己的。

| 名稱 | 個性 | 適合 |
|---|---|---|
| **Muted Chrome 霧鉻** | 低飽和、硬朗影調、深而沉穩的藍天，綠色收斂成橄欖但不變青 | 紀實、街拍、建築 |
| **Street Negative 街頭負片** | 硬反差、偏青天空、冷調暗部、暖而不黃的高光、深沉的紅 | 街頭、城市、生活 |
| **Portrait Soft 柔膚人像** | 明亮低反差、乾淨膚色（不橘不紅）、柔和的綠與藍 | 戶外人像 |
| **Vivid Landscape 鮮明風景** | 飽和而受控、天空漸層深邃、黃綠／草綠／深綠層層分開 | 風景、旅行 |
| **Cine Daylight 電影日光** | 低反差低飽和、膚色仍有血色、暗部微青、寬容度高 | 電影感、後製底片 |
| **Nostalgic Summer 懷舊夏日** | 琥珀色陽光、柔和天空、溫暖黃綠，白色依然乾淨 | 夏天、回憶感 |
| **Clear Daylight 晴透日光** | 明亮通透、略冷的空氣感、乾淨天空與純白 | 晴天、日常、海邊 |
| **Summer 400 夏日 400** | 溫暖飽滿的紅黃、青藍天空、明顯顆粒、膚色自然 | 夏日快照 |

## 色彩科學（每款都有自己完整的參數）

配方在 `daylight.py`，引擎在 `look.py`，依序：

1. **色彩管理**：sRGB → 線性光 → OKLab 工作空間 → 色域映射 → sRGB
2. **白平衡**：線性光、保持亮度的增益
3. **12 色相區段 HSL**：紅、膚色、琥珀、黃、**黃綠**、**草綠**、**藍綠**、**青**、**天藍**、**深藍**、紫、洋紅，區段之間平滑過渡
4. **暗部 HSL**：深綠、深藍另外一張表，跟亮部分開調整
5. **飽和度／自然飽和**
6. **色調映射**：filmic 曲線（18% 灰斜率、柔和趾部、高光肩部，不裁切）
7. **色度上限**：每個色相區段柔性上限 → 天空、植被濃郁但不螢光
8. **高光色彩滾降**：接近白色時顏色平滑淡出 → 雲、白牆、白衣乾淨
9. **三向色彩分級**：暗部／中間調／高光
10. **乾淨白**：接近純白的中性灰保持中性
11. **可選顏色**：紅、黃、綠、青、藍、洋紅、白、中性灰、黑 各自 CMYK 調整
12. **獨立 RGB 曲線**：R、G、B 通道交叉

整條管線烘焙成 33³ 3D LUT 交給 GPU（只是運算載體：與直接運算的誤差平均 < 0.2 階、99% 像素 < 2 階），
顆粒、光暈、Halation、暗角在 GPU 另外運算，任何解析度都一樣。

## 驗證：`daylight_lab.py`

```bash
python3 daylight_lab.py                # 數值檢查 + 對照圖 preview/daylight/
python3 daylight_lab.py --checks-only
```

測試照片（`photos/daylight/`，不放進 repo）：1 藍天白雲、2 綠色樹木、3 日本街道、4 建築與水泥、5 白色、6 人像、7 逆光，另有海灘人像、紅帽人像、乾草地、陰天街道、燈塔等。
App 裡的 **Daylight Filter Lab**（設定 → 濾鏡品質工具）可以把每個場景換成自己的照片，八款並排比較，點任一款看前後對照。
