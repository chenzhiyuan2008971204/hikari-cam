# 攝影師風格濾鏡工具

把 `presets.py` 裡的每個風格烘焙成 33³ 的 3D LUT（`app/src/main/assets/looks/*.cube`），並產生
`StylePresets.kt`。顆粒、暗角、光暈這類空間效果交給 app 的 shader，顏色全部在 LUT 裡。

需要 Python 3、numpy、Pillow。

```bash
cd tools/looks
python3 build.py --photos 你的測試照片資料夾      # 烘焙 + 產生預覽圖到 preview/
python3 build.py --only hamada,leiter            # 只看幾個風格的預覽
```

## 乾淨畫面規則

`build.py` 烘焙前會自動檢查每個風格，不合格就停止：

| 檢查 | 限制 |
|---|---|
| 純白、92% 灰的偏色 | OKLab 色度 ×100 ≤ 2 / ≤ 3 |
| 純白最暗通道 | ≥ 0.95（白要夠白） |
| 純黑最亮通道 | ≤ 0.045（黑不發灰） |
| 三種膚色（淺、深、東亞） | 色相偏移 ≤ 12°，色度變化 0.5～1.7 倍 |
| 顆粒、漏光、光暈、暗角 | 不預設（需要時用 app 滑桿加） |

引擎本身也會讓接近純白的區域維持中性、分離色調在接近純黑時淡出，並降低分離色調對膚色的影響。

## 為什麼舊濾鏡跟攝影師的照片有落差

舊的參數只有整張圖的色溫、飽和、曲線。但攝影師的色調幾乎都是**分色相**的：
濱田英明的綠是淡的、帶黃的；Saul Leiter 整體褪色，紅色卻保留飽和；王家衛的陰影偏青綠，紅色和琥珀色卻很熱。
`look.py` 在 OKLab 色彩空間裡處理：

- 8 個色相區段（紅、橘、黃、綠、青、藍、紫、洋紅）各自調整色相、飽和、明度，區段之間平滑過渡
- 明度曲線（不會讓顏色偏移）、依亮度降低飽和、陰影／中間調／亮部分離色調
- 黑白用通道混合（類似鏡頭前加濾色片），軟性色域壓縮（飽和區不會被硬切而失去層次）

## 用真實作品縮小落差：`fit.py`

這些風格是根據我對攝影師公開作品的了解手調出來的，**沒有對照過真實照片**，一定還有落差。
要縮小落差，請準備參考照片：

1. 把 10～30 張該攝影師的代表作放進 `refs/<風格名>/`（截圖也行，裁掉邊框和文字）
2. `python3 fit.py hamada refs/hamada --photos 測試照片` 會先列出落差：
   明暗分布、陰影／中間調／亮部偏色、各色相的飽和度與色相
3. 加上 `--write` 會自動修正並寫到 `fitted/hamada.json`，`build.py` 之後會優先使用它
4. 再跑 `build.py` 看預覽

明暗和偏色的修正很可靠，跟照片內容無關。各色相的飽和度則會受照片內容影響
（例如參考照片裡天空多，藍色就會偏多），所以這部分的修正有壓低幅度、也有上限，修正後請一定要看預覽確認。
